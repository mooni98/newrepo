this is aBMI Calculator
   projects repo

A simple and responsive BMI (Body Mass Index) calculator that helps users check their BMI based on height and weight inputs.

⸻

Tech Used:
	•	HTML
	•	CSS
	•	JavaScript

⸻

Project Features:
	•	Allows users to enter their height (in cm) and weight (in kg)
	•	Calculates BMI automatically when the user clicks “Calculate”
	•	Displays the BMI result along with a health status message (e.g., Underweight, Normal, Overweight)
	•	Basic input validation to prevent blank or invalid entries
	•	Clean and responsive design for desktop and mobile

⸻

How to Use:
	1.	Enter your height in centimeters
	2.	Enter your weight in kilograms
	3.	Click the “Calculate” button
	4.	Your BMI result and status will appear below the form

⸻

Why I Built This:

This project was built to practice handling user input, performing calculations, and dynamically updating the user interface using JavaScript.
